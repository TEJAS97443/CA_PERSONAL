## Tooling problems

- `build.py --check` writes nothing, so `/q/<id>` showed "Question not found" until I ran a full `build.py`. Peers report the same.
- check.py's running-head heuristic treats very common line shapes as page furniture and drops those lines. The shapes are `#,#,#` (a lone Indian-grouped number) and `#.` (a lone list number). In formula-heavy or watermarked files this produces false number mismatches, which have to be accepted by hand.
- check.py reads Unicode superscript digits (¹²³⁴) as digits.
