## Tooling / guide notes
- `build.py` (full) failed once because of another lesson's maths error (fm.wc.receivables) and wrote no data; `tools/shot.sh` for my new lesson then silently showed the Paper 5 page instead of the lesson. A shot of a lesson missing from data/ could warn.
- Flow diagrams: which side a decision's yes/no children go is set by node order in `nodes`, not by edge order; a back edge from the left child routes behind the right child (I reordered nodes to fix). Three-line labels overflow end/process boxes; two lines fit. Edge labels on short vertical edges overlap the arrow unless `gapY` is raised (64 worked). Worth a line in diagram-examples.json.
- The probe's `scrolls-inside` counts every cell of a sideways-scrolling table (16 for the audit programme lesson: its 5-column ICAI layout scrolls on a phone, which seems unavoidable for that format).
- Locating a diagram inside preview slices is guesswork; a preview option that prints each diagram's slice and y offset would save image budget. macOS has no `timeout` command (minor).
