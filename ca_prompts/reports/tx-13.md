## Tooling
- check.py's marks parser reads "(N Marks)", "(a x b = c Marks)" and "(a + b = c Marks)", but not a sum with no total such as "(1 + 3 Marks)" (Q5(c) of the January 2025 P4 paper, the only one in the sources). Its 1 and 3 had to be accepted as numbers. The marks comparison still passed only because of how the OR's marks are counted. Possible fix: make "= N" optional in `MARKS_SUM` and take the sum as the total. I did not change the tool.
- check.py drops a lone number on a page's first line as a page number, even when it is a fraction's numerator. This forced the accepted 5 in MTP May 2025 S1.
- `build.py --check` does not write `data/`, so a new document only shows in the app after someone runs a full build. Each time, the data was rebuilt by another job's build within a minute or two, so I did not run a full build myself.
- About 25 page images were rendered per document, cropped where possible.
