## Tooling problems (for bank-core)
1. check.py's running-head detection removes the "Question N" lines of old-scheme Suggested Answers. So question numbers need `accept:` on one or both sides in every old P8 / P3 file.
2. Groupings split by spaces in the text layer ("₹ 4, 80, 000", "1,50, 000") are not paired by pair_splits when there are three or more pieces. This forces long accept lists.
3. NUM's lookbehind `(?<![\d.])` reads "Rs.8,00,000" as 0.
4. Marks in square brackets ("[10 Marks]", used by old MTPs) are not parsed, so marks go unchecked for these papers.
5. Ran `build.py` (not --check) three times to write data for the screenshots. One run came from `build.py --help`, which builds instead of printing help.
