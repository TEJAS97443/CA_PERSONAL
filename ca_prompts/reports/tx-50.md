## Tooling notes
- check.py's number regex does not start a number right after a ".", so the PDF's math-italic "𝑅𝑠.9,00,000" reads differently from a KaTeX `\text{Rs.}9{,}00{,}000`. The fix is to keep "Rs." and the number inside one `\text{Rs.9,00,000}`. This hit nov2022-s2 and is now fixed there. Other transcribers may run into the same thing.
- `build.py --check` does not write data/, so the app does not show a new document until a full `build.py` has run. I ran the full build once (by accident with `--help`, which `build.py` does not have) and once on purpose before the last screenshot.
- seg.py `--info` says the mirror's banner lines are removed from the .txt, but `seg.py <pages>` still prints them ("Downloaded From www.castudynotes.com").
