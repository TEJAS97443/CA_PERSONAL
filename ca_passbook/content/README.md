# content/

Everything an author edits.

| path | what |
|---|---|
| `syllabus/syllabus.txt` | the ICAI Group II tree (papers → chapters → sub-topics) — see its header for the grammar; the lead owns it |
| `subjects/<paper>/<lesson-id>.md` | one lesson per sub-topic, `<paper>` = `cma` (Paper 4), `aud` (Paper 5), `fm` (Paper 6A), `sm` (Paper 6B); contract in `docs/CONTENT_GUIDE.md` |
| `sections.json` | the lesson `##` sections, their order, which are required and their reading depth (Quick / Exam / Deep) |
| `exam.json` | the exam calendar (ICAI's announcement: Group II paper days, times, source URL, SHA-256, checked date) |
| `labs.json` | catalogue of interactive labs (metadata only; code lives in `app/js/labs/`); change it with `tools/lab_status.py` |
| `flashcards/<paper>.md` | extra standalone flashcards (`Q:: … / A:: …`) |
| `card-ids.json` | generated by build.py (flashcard id ledger); never edit by hand |

There is no question bank yet: `pyq/` holds empty source manifests so the build runs; the ICAI bank (past papers, RTPs, MTPs with ICAI's
suggested answers) is a later job.
