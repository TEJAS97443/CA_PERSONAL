kmap — four variables, corner group

vars: 2–5 names, first = most significant bit ("ABCD" or ["x1","x2","x3"]). Values from m (minterms → 1), d (don't-cares → X), M (maxterms → 0, the rest 1) or grid (rows top to bottom in the map's Gray order, e.g. ["1001","0110",…], 0/1/X). groups: {term:"B'D'"} or {cells:[0,2,8,10]}, plus color a–h and label (defaults to the term, else the term is worked out from the cells). Groups wrap round the edges and the four corners by themselves; a group that is not a rectangle of 1, 2, 4, 8 or 16 adjacent cells, or that mixes 1s and 0s, is an error ("wrong": true draws a deliberately wrong group, dashed). index:true prints the minterm number in each cell; hl:[5,7] or {"5":"bad"} tints cells; zeros:false hides the 0s; split:1 puts one variable on the rows; cell: cell size in px (44); legend: false or "below".

  2,
  5,
  7,
  8,
  10,
  13,

 "index": true,
 "groups": [
  {
   "term": "B'D'",
   "color": "a"

   "term": "BD",
   "color": "b"

circuit — two-level NAND–NAND, input bus, highlighted path

parts: {id, kind, at:[column, row]} on a grid of grid:[70,46] px per column/row (fractions allowed; a pin such as "g1.2" in place of a number lines the part up with that pin). Gates: and, or, not, nand, nor, xor, xnor, buf; n = inputs (2); input pins g1.1 … g1.n top to bottom, output g1.y (or just g1); neg:[1,3] adds inversion bubbles on inputs, neg:["y"] on the output; label writes a small name inside. Terminals: kind in / out, side = where the wire attaches (in: r, out: l; t/b for lines from above or below), label ("~A" draws A with a bar). wires: ["A","g1.1"] or {from, to (a pin or a list = fan-out sharing one trunk), x: trunk column, y: detour row, via:[[c,r],…] waypoints, label, labelAt:[c,r], color, dash}. Routing is orthogonal; trunks of different nets in the same gap are spread apart automatically; a dot marks a junction of one net, crossing nets get no dot. path:["B","g2","g4","F"] colours those parts and the wires between consecutive ones (pathColor, default bad); color on a part or wire colours just that one.
